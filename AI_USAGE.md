# AI Usage — Pair_Programming_Team_32

We used AI coding assistants as development support while working on this lab. We used them to clarify parts of the
requirements, discuss architecture and implementation choices, debug and refactor code, and review notebook
organization. They also helped us improve prompts, retrieval logic, agent orchestration, documentation, diagrams,
and the IEEE report presentation. We reviewed the suggestions, ran the code ourselves, and made the final decisions
as a team.

Both Shreya and Zoheb contributed to Parts 2 and 3, as well as Part 1. The table below summarizes the main areas
where AI-assisted development support was used by each team member.

| Tool | Used by | What for |
|---|---|---|
| Claude Code (Anthropic) | Shreya | Support with understanding the requirements, Part 1 and Part 2 implementation, contributions to the Part 3 workflow, debugging notebooks and scripts, checking experiment organization, improving documentation, drafting the first version of the report text (which we then rewrote in our own words), and the architecture diagrams and IEEE formatting. |
| Claude Code (Anthropic) | Zoheb | Support with the Part 1 multimodal pipeline, contributions to Part 2, the Part 3 agent workflow and application structure, debugging and testing, prompt organization, and documentation. |

The assistants were used for suggestions and development support; they did not replace our review of the code or
experiments. We ran the notebooks and tests, checked the outputs, selected the final system decisions, and wrote the
final explanations as a team.
